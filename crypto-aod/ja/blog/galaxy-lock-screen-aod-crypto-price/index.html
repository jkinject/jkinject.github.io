Galaxyのロック画面・AODにビットコインなど仮想通貨の価格を表示する方法（One UI 7以降）

Crypto AOD 開発者 · 2026-11-27

この記事は、Galaxy向けの価格ウィジェットアプリ「Crypto AOD」の開発者が書いています。自分のアプリも紹介しますが、Galaxy側の設定やアプリを使わない方法も含めてまとめました。アプリを入れない人にも役立つように書いたつもりです。

結論：One UI 7以降なら「ロック画面ウィジェット＋AOD」で、画面オフのまま見られる

GalaxyでAOD（Always On Display）をオンにしていると、ロック画面に置いたウィジェットがAODにもそのまま表示されます。ロック画面のウィジェット枠に価格を出せるアプリを置けば、画面が消えている状態でもビットコインやイーサリアムの価格を確認できます。スマホを持ち上げてロックを解除し、アプリを開く、という手順がいらなくなります。

用意するものは次の3つです。

  • One UI 7以降のGalaxy（バージョンは「設定」→「端末情報」→「ソフトウェア情報」で確認できます。機種により異なる場合があります）
  • ロック画面ウィジェットに対応した価格表示アプリ
  • AODをオンにしておくこと（省電力モード中はAODが使えません）

先に知っておきたい、ロック画面ウィジェットの仕様

ロック画面ウィジェットは、ホーム画面のウィジェットとはルールがかなり違います。あとで「思っていたのと違う」とならないよう、先に押さえておきます。

  • 置けるのは合計4マス分まで。 Samsungの公式サポートに「ウィジェットは最大4マス分」と書かれています。
  • サイズは1×1と2×1。 筆者がアプリを作る過程で確かめた限り、一般のアプリがロック画面の枠で使えるサイズはこの2種類です。4マスなので、2×1を2つ、1×1を4つ、2×1を1つと1×1を2つ、といった組み合わせになります。
  • 一覧に出るのはロック画面向けのウィジェットだけ。 ホーム画面に置いているウィジェットが全部並ぶわけではありません。
  • ウィジェットの後ろの半透明の背景はシステムが描いています。 アプリ側では消せず、色はロック画面のテーマに合わせて変わります。

参考：ロック画面のカスタマイズ方法（Samsung公式サポート）

手順1：AODをオンにする

Samsung公式サポートの手順です。

  1. 「設定」アプリを開く
  2. 「ロック画面とAOD」をタップ
  3. 「Always On Display」をタップ
  4. スイッチをオンにする

表示タイミングは「自動」「タップして10秒間表示」「常に表示」「特定の時間のみ表示」「新着通知受信時に表示」から選べます（「自動」はOne UI 6.1以降）。机の上でいつでも価格を見たいなら「常に表示」、夜間は消したいなら「特定の時間のみ表示」が向いています。

省電力モードがオンのあいだは、AODは使えません。急にAODが表示されなくなったときは、まず省電力モードを確認してください。

参考：Always On Displayを使用する方法（Samsung公式サポート）

手順2：ロック画面にウィジェットを追加する

入り口はいくつかあり、機種やバージョンで画面の名前が少しずつ違います。どれから入っても同じ編集画面にたどり着きます。

  • Samsung公式の手順： ホーム画面の何もない場所を長押し →「壁紙とスタイル」→ 左側のロック画面の画像をタップ →「ウィジェットを追加」→ ウィジェットとサイズを選んで「完了」
  • 設定アプリから： 「設定」→「ロック画面とAOD」→「ロック画面を編集」→「ウィジェット」（機種により異なる場合があります）
  • ロック画面から： ロック画面を長押しして編集画面を開き、ウィジェットの枠をタップ（機種により異なる場合があります）

外したいときは、編集画面でウィジェットのマイナス（－）アイコンをタップします。

手順3：Crypto AODで価格を出す場合

ここからは自分のアプリの例です。ほかのアプリでも、大まかな流れは似ていると思います。

  1. アプリで銘柄を追加します。Upbit・Bithumb・Binance・Coinbase・OKX・Bybit・Krakenの7つの取引所から、名前・シンボル・通貨ペアで検索できます。取引所を混ぜて登録してもかまいません。
  2. 手順2の編集画面で「Crypto AOD · ロック画面 1×1」か「Crypto AOD · ロック画面 2×1」を選びます。
  3. そのウィジェットに表示する銘柄を選びます。ウィジェット1つにつき1銘柄です。
  4. アプリの「ロック画面 · AOD をカスタマイズ」で、ティッカー・価格・前日比の文字サイズをそれぞれ変えたり、非表示にしたりできます。上がったか下がったかは▲▼で表示されます。
  5. 更新間隔を1分・5分・15分から選びます。ウィジェットをタップすれば、その場で価格を取り直します。

アプリ内のボタンで開けるのは「ロック画面とAOD」の設定画面までです。Samsungのロック画面編集画面は一般のアプリから直接開けない仕組みになっているので、そこから先は手順2のとおりにタップしてください。

1×1と2×1、どちらにする？

1×1は小さく、桁の多い価格だと窮屈になりがちです。価格だけを大きく出したいなら、ティッカーや前日比を隠すと見やすくなります。2×1は横に余裕があるので、ティッカー・価格・前日比を並べても読みやすいです。たとえば2×1を2つ並べて、ビットコインとイーサリアムを1つずつ表示する使い方ができます。

円建ての価格について

Crypto AODが対応している7つの取引所に、国内の取引所は入っていません。円建て（JPY）で見られるのは、KrakenのBTC/JPYやETH/JPYのように、対応取引所が円の通貨ペアを扱っている銘柄だけです。銘柄を探すときに建値をJPYで絞り込むと、選べるペアが分かります。国内取引所の価格そのものをロック画面で見たい場合は、その取引所の公式アプリがロック画面ウィジェットに対応しているかを確認してみてください。

画面オフで更新が止まるときは

AODに出しっぱなしにする使い方では、バックグラウンドでの更新がいちばんの壁になります。Crypto AODで確認してほしい点は次のとおりです。

  • 1分・5分間隔にする場合： 「バッテリー最適化の除外」と「アラームとリマインダー」の許可が必要です。15分間隔なら追加の権限はいりません。
  • 3日以上アプリを開いていない場合： Galaxyのスリープ機能でアプリが止められ、更新が止まることがあります。「設定」→「バッテリーとデバイスケア」→「バッテリー」の中にある、バックグラウンドの使用を制限する項目で、スリープさせないアプリに登録してください（項目名は機種やバージョンにより異なる場合があります。アプリの設定タブにも案内があります）。
  • 通信できないとき： 更新に失敗したり、オフラインになったりしても、ウィジェットには最後に取得した価格と時刻が残ります。時刻が古いままなら、更新が止まっているサインです。

参考：バッテリーを最大限に活用する方法（Samsung公式サポート）

無料版とプレミアム

無料版では1銘柄を、ロック画面・AOD・ホーム画面のすべてのウィジェットで表示できます。プレミアムは最大5銘柄までで、サブスクリプションではなく買い切りです。インストール後7日間は無料で試せます。料金はGoogle Playのページで確認してください。アカウント登録やログインはなく、広告も入っていません。

Galaxy以外のスマホの場合

ロック画面・AODウィジェットはOne UI 7以降のGalaxy専用です。ほかのAndroidスマホでは、ホーム画面ウィジェット（最大5銘柄のリスト表示）だけが使えます。

まとめ

  • One UI 7以降のGalaxyなら、ロック画面に置いたウィジェットがAODにも表示される
  • ロック画面の枠は合計4マス、サイズは1×1と2×1
  • AODは「設定」→「ロック画面とAOD」→「Always On Display」でオン。省電力モード中は消える
  • 画面オフで更新を続けるには、バッテリー最適化とスリープの設定がポイント

アプリの詳しい紹介はCrypto AODの紹介ページに、ダウンロードはGoogle Playにあります。

表示される価格は、各取引所の公開APIにもとづく参考情報です。Crypto AODには売買・注文・送金の機能はありません。Samsung、Galaxy、One UI、各取引所とは提携関係のない独立したアプリです。
