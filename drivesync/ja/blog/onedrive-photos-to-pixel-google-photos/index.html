OneDriveの写真を古いPixelに移して、Google フォトにバックアップする方法【機種別の条件と注意点】

DriveSync開発チーム · 2026-11-25

OneDriveの容量がいっぱいになってきた。でも引き出しには、しまったままのPixel 4aやPixel 5がある。そんな方に向けた記事です。

Pixel 5以前のPixelには、その端末からGoogle フォトにバックアップした写真と動画を無料・無制限で保存できる特典が残っています。OneDriveにたまった写真をそのPixelに移してバックアップすれば、OneDriveの容量を空けられます。

書いているのは、この用途に合わせてAndroidアプリ「DriveSync」を作っている開発チームです。アプリを入れない方にも役立つように、条件と注意点から先にまとめます。

  • 無料・無制限になる条件は機種ごとに違います。Pixel 5a (5G) とPixel 6以降は対象外です。
  • Pixel 2〜5で無料になるのは「保存容量の節約画質」です。元の画質のまま無料で残るのは第1世代のPixelだけです。
  • OneDriveの容量は、ファイルを消しただけでは空きません。OneDriveのごみ箱を空にしてはじめて空きます。

無料・無制限でバックアップできるPixelはどれか

Googleのヘルプには「Google Pixel 5 以前の Google Pixel をお使いの場合、そのデバイスから無制限ストレージに写真と動画を無料でバックアップできます」と書かれています。機種ごとの条件は次のとおりです（2026年11月25日に日本語のヘルプで確認）。

機種無料・無制限でバックアップできる範囲
Pixel（第1世代、2016年）元の画質で無制限
Pixel 22021年1月16日より後にバックアップした分は、保存容量の節約画質で無制限
Pixel 32022年1月31日より後にバックアップした分は、保存容量の節約画質で無制限
Pixel 3a・4・4a・5保存容量の節約画質で無制限（元の画質でバックアップすると保存容量を使います）
Pixel 5a (5G)、Pixel 6以降無料の無制限バックアップはありません

出典はGoogle フォト ヘルプの写真と動画のバックアップの画質を選択する（Androidのタブの「Google Pixel での Google フォトのバックアップについて」）と、Google フォトのアクティビティとストレージについてです。

対象になるのは「そのPixelからバックアップした写真と動画」です。ヘルプに終了時期は書かれていませんが、Googleはこの条件を変更することがあります。始める前に、上のヘルプで最新の内容を確認してください。

「Pixel 5a (5G) も対象」と書いているブログもありますが、Googleのヘルプが挙げているのは「Pixel 5 以前」「Pixel 3a～Pixel 5」です。迷ったときはヘルプの記載を基準にしてください。

「保存容量の節約画質」は元の画質ではありません

Googleのヘルプによると、保存容量の節約画質では写真は容量を節約するために圧縮され、16MPを超える写真は16MPに縮小されます。動画は、解像度が1080pを上回る場合に1080pへサイズ変更されます。字幕など一部の情報が失われる可能性がある、とも書かれています。

つまり、元のファイルをそのままPixelに移しても、Pixel 2〜5で無料でGoogle フォトに残るのは圧縮されたものです。Pixel 3a〜5で「元の画質」を選べばそのまま保存できますが、その分はGoogle アカウントの保存容量を使います。

元のファイルが大事な方は、OneDriveのごみ箱を空にする前に、元のファイルを外付けSSDやパソコンなど別の場所にも保管してください。ごみ箱を空にしたあとは、OneDriveから取り戻せません。

全体の流れ

  1. PixelのGoogle フォトでバックアップをオンにし、画質を確認する
  2. OneDriveの写真と動画を、Pixelの DCIM/Camera に移す
  3. Google フォトのバックアップが終わったことを確認する
  4. OneDriveのごみ箱を空にする
  5. Pixelの空き容量が足りなくなったら、バックアップ済みの写真を端末から消して、続きを移す

画質は、Google フォト アプリの上部にあるプロフィール写真から [Google フォトの設定] → [バックアップ] → [写真と動画の画質] で確認できます。Pixel 3a〜5で無料の範囲に収めたい場合は「保存容量の節約画質」を選びます。

保存先を DCIM/Camera にするのは、Google フォトが追加の設定なしでバックアップするフォルダだからです。ほかのフォルダに入れた場合は、Google フォトでそのフォルダのバックアップをオンにする必要があります。

Pixelの空き容量より写真のほうが多くても大丈夫です。バックアップが終わった写真は、Google フォト アプリで選んで「デバイスから削除」すれば端末から消せます（Googleのヘルプ：写真や動画を削除する）。空きができたら続きを移します。

OneDriveの写真をPixelに移す方法

パソコンを経由する

ブラウザーでOneDriveを開いて写真をパソコンにダウンロードし、USBケーブルでつないだPixelの DCIM/Camera にコピーします。特別なアプリは要りませんが、パソコン側に空き容量が必要で、OneDrive側の元ファイルは自分で消すことになります。

OneDriveの公式アプリで保存する

Android版のOneDriveアプリでは、ファイルを複数選んで [保存] をタップし、保存先のフォルダーを選べます（Microsoftのヘルプ：OneDrive ファイルをモバイルにダウンロードする方法）。枚数が少なければこれで十分です。こちらも、元ファイルはあとから自分で削除します。

汎用の同期アプリを使う

FolderSyncやSyncthingのような同期アプリで、古いPixelを「アップロード専用機」にしている方もいます（例：QiitaのFolderSyncとSFTPでPixelに写真を送る構成の記事）。これらのアプリでOneDriveの写真を移す使い方は私たちが検証していないので、紹介にとどめます。

DriveSyncを使う

DriveSyncは、まさにこの作業のために作ったアプリです。

  • 写真と動画を、フォルダを選ばずに DCIM/Camera へ直接保存します（Android 10以降。アプリ自体はAndroid 8以降で動きます）。
  • ファイルは元のまま、1バイトも変えずにPixelへ移します。まずコピーし、サイズとハッシュで検証して、確認できた場合にのみOneDrive側の元ファイルを削除します。
  • OneDrive全体の画像、画像+動画、すべてのファイルをまとめて移せます。移したいファイルやフォルダだけを選ぶこともできます。
  • ファイルはスマートフォンとMicrosoftの間で直接転送されます。DriveSyncのサーバーも、新しく作るアカウントもありません。サインインにはMicrosoft公式のサインインを使います。

使い方は次のとおりです。

  1. Pixelにインストールします。サインインの前に、サンプルファイルでアプリ全体を試せます。
  2. ご自身のMicrosoftアカウントでサインインします。
  3. 移す範囲（画像、画像+動画、すべてのファイル）を選ぶか、ファイルやフォルダを自分で選びます。
  4. 内容を確認して開始します。速度と残り時間が表示され、画面を消しても移動は続きます。
  5. 終わったら移動履歴を確認します。失敗した項目は再試行できます。
無料プランは、同時3件、1ファイル最大100MB、広告ありです。100MBを超えるファイル（長めの動画など）は無料プランでは移せず、OneDriveに残ります。その分はパソコン経由で移すか、プレミアム（買い切り。サブスクリプションではありません。同時10件、1ファイル最大4GB、広告なし）をご検討ください。

なお、動作を確認しているのは個人用のMicrosoftアカウントのOneDriveです。DriveSyncは独立したアプリで、MicrosoftやGoogleとの提携や承認を受けたものではありません。

OneDriveのごみ箱を空にして、はじめて容量が空きます

見落としやすいのが最後のこの一手です。

OneDriveで削除したファイルは、まずOneDriveのごみ箱に移動します（Microsoftのヘルプ：OneDrive でファイルまたはフォルダーを削除する）。DriveSyncが検証後に削除した元ファイルも同じで、ごみ箱から復元できます。

そして、Microsoftのヘルプ「OneDrive がいっぱいだと表示される」では、ストレージの使用量に数えられるものとして、ごみ箱内のアイテムも挙げられています。ごみ箱に残っているあいだは、容量は空きません。

順番は次のとおりです。

  1. PixelのGoogle フォトで、移した写真のバックアップが終わっていることを確認する
  2. 元のファイルを残したい写真は、別の場所に保管してあることを確認する
  3. ブラウザーでOneDriveを開き、左側の [ごみ箱] を開いて、中身を完全に削除する

削除が使用量の表示に反映されるまで、少し時間がかかる場合があります。「消したのに容量が減らない」と感じたら、まずごみ箱を見て、それから少し待ってみてください。

おわりに

ここまでの作業は、手作業でも同じようにできます。枚数が多くて、コピーの確認や削除を1件ずつやっていられないときは、DriveSyncを試してみてください。アプリについては紹介ページにもまとめています。

DriveSync: OneDriveからスマホへ

OneDriveの写真をPixelに移してGoogle フォトでバックアップ。検証後に元ファイルを削除します。
